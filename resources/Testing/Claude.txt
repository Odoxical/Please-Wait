Here's a full walkthrough of how it works:

To use it: create an empty scene with a Node3D root and attach this script to it. Hit Play — the whole scene (bodies, joint, camera, light) is built in code.

How the spring is configured

Generic6DOFJoint3D gives you independent control over each of the 6 degrees of freedom. For a vertical spring you only need to touch three things on the Y axis:

FLAG_ENABLE_LINEAR_SPRING      → turns the spring on
PARAM_LINEAR_SPRING_STIFFNESS  → the k constant (N/m)
PARAM_LINEAR_SPRING_DAMPING    → resistance to oscillation
PARAM_LINEAR_SPRING_EQUILIBRIUM_POINT → where the spring force = 0
The X and Z linear axes are "locked" by setting lower limit == upper limit == 0, so the bob can only travel vertically. All three angular axes are locked the same way to prevent it from spinning.

Physics note — gravity shifts the rest position The equilibrium point is where spring force is zero, not where the bob actually hovers. Gravity adds a constant downward pull, so the bob settles at the point where k·x = m·g, a bit lower than rest_length. This is exactly how a real mass-spring behaves. If you want the bob to visually rest at exactly rest_length, set the equilibrium point higher by (bob_mass * 9.8) / spring_stiffness.

Controls at runtime

Key	Effect
Space	Upward impulse — compresses the spring
Down	Downward impulse — stretches it
R	Resets position and kills velocity
The helix visual uses ImmediateMesh with PRIMITIVE_LINE_STRIP, rebuilt every _process frame by interpolating the coil centre between the anchor and bob's global positions, then adding the cosine/sine offset in XZ. All the key values (helix_coils, helix_radius, spring_color) are exported so you can tweak them in the Inspector.
